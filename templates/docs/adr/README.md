# Architecture decisions

`NNNN-slug.md`, sequential, never reused. Format and when to write one:
`.claude/skills/architect/ADR-FORMAT.md`.

New ADRs start as `proposed`; **only the user sets `accepted`**. An accepted decision is never changed in
place – it is superseded by a new ADR. Editorial fixes (typo, outdated path, formatting) are allowed with a dated line
under `## Editorial changes`. The hooks enforce that.
